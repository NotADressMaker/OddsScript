# Introduction to VigScript

VigScript is an open-source programming language and analytics toolkit built specifically for sports betting. It combines a custom betting-focused scripting language with odds math, bankroll management tools, predictive models, APIs, dashboards, and data pipelines for researching, modeling, and testing betting strategies in a structured, repeatable way.

The language is the center of the project: write strategies as code, backtest them, simulate risk, and explain results before risking capital.

VigScript emphasizes expected value, vig/devig, bankroll drawdown, longest losing streak, risk of ruin, Martingale step probability, required bankroll, closing line value, and variance.
