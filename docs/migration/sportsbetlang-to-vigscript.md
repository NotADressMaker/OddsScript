# Migrating from SportsBetLang to VigScript

SportsBetLang is now VigScript. The public project identity is VigScript because the custom betting-focused language is the center of the toolkit.

- `.vig` is the preferred script extension for new VigScript programs.
- `.sportsodds` remains supported as a legacy compatibility format.
- `vigscript` is the preferred CLI command.
- Older commands such as `sportsbetlang` and `betlang` remain aliases where supported.
- Python imports using `sportsbetlang` remain available during the transition to avoid breaking existing projects.

VigScript is for education, research, backtesting, simulation, transparency, and risk analysis. It does not promise profits or winning picks.
