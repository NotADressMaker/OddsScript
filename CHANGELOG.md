# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0-alpha] - 2024-03-18
### Added
- Ruff and mypy configuration for linting, formatting, and type checking.
- CI checks for tests, linting, formatting, and type checks.
- Version metadata is now sourced from `sportsbetlang/__version__.py`.

### Changed
- Build configuration now pins dependency ranges for reproducible builds.
- Formatting and linting helpers received updated type hints.
